# CBAS Analysis

Analysis code for circadian behavioral organization using CBAS behavioral classification data.

## Current analyses

- Phase × Behavior Mutual Information
- Structure-preserving circular-shift null
- Phase-bin width sensitivity
- Phase-bin origin sensitivity

For definitions and interpretation of MI output variables, see `MI_VARIABLES.md`.
For definitions and interpretation of recurrence output variables, see `RECURRENCE_VARIABLES.md`.
